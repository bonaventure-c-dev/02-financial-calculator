# 📈 Interactive Compound Interest Calculator

A clean, responsive, client-side web application that calculates compound interest and total investment growth over time. 

Built as **Project 02** of the Web Development & Software Engineering Portfolio series.

---

## 🚀 Features
* **Dynamic Calculations:** Computes future balance, total contributions, and total interest earned in real-time.
* **Monthly Compounding Logic:** Accurately accounts for initial investment, recurring monthly contributions, annual interest rate, and timeline in years.
* **Currency Formatting:** Automatically formats inputs and calculations into clean USD currency strings.
* **Responsive Dark Theme UI:** Styled with a modern, financial dashboard aesthetic.

---

## 🛠 Tech Stack
* **HTML5:** Semantic structure and form elements.
* **CSS3:** Custom styles, CSS Flexbox layout, and variables.
* **JavaScript (Vanilla ES6+):** Form event listeners, dynamic DOM updates, and math calculations.
